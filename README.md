# Celfnow Panel · 橙风面板

给 Minecraft 基岩版专用服务器（BDS）用的 Windows 桌面管理面板。
即开即用，不依赖网页，内存占用低。

用户交流群:1129932511

> **目前是 Beta 阶段**，有 bug，也还有没做的功能。欢迎试用，欢迎反馈。

## 能做什么

- **多服务器管理**：一个面板管理多个服务器，每个服务器一张卡片
- **服务器信息**：运行状态、在线人数、运行时长，不用翻控制台
- **控制台和快捷命令**：启动 / 停止、白名单、管理员（OP）、快捷关服、发消息
- **入服欢迎**：玩家进服后自动说一句，支持 `{player}` 换成玩家名、多行；发送内容可预览，**默认关闭**
- **性能监控**：CPU、内存、上行、下行
- **在线统计**：同时在线人数趋势，玩家在线时长排行
- 还有：快捷日志、在线玩家（设为 OP / 踢出）、文件管理、服务端设置（`server.properties`）、断网自动关服（默认关闭）
- 深色 / 浅色两套主题

## 下载和使用

1. 到本仓库的 **Releases** 页面下载最新版安装包，安装后运行
2. 第一次打开，点「添加服务器」，选择 `bedrock_server.exe` 所在的文件夹
3. 想用「在线统计」「入服欢迎」，请**用面板来启动服务器**（面板需要读到控制台日志）

测试版系统要求：Windows 64 位。

> 安装包没有做代码签名，Windows 可能弹出「已保护你的电脑」的提示。确认文件来自本仓库后，点「更多信息 → 仍要运行」即可。

## 已知限制

- 在线统计只统计**本次开服期间**，服务器每次重启后清零；面板没开着时的进退服不会被记录
- 文件管理里的删除不可撤销，操作存档文件时请小心
- 暂时只支持基岩版服务器 后续依据情况适配JAVA
- 暂时只支持 Windows，没有 Linux / macOS 版
